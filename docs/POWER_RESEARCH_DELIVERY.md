# Progressions and Foundation expansion — November 3, 2026

This release adds 23 searchable progression families, including separate straight-arm strength, Pike Compression, Straddle Compression, Stalder, Pike Pressing, levers, unilateral strength and Foundation. The bundled catalog now contains 264 real exercise/drill records. The 31 new editorial drills have no fabricated video URLs or verification badges.

Five working levels and explicit self-reported capabilities apply to skill generation, support exercises, substitutions, studio focus links, manual exercise imports and old active drafts. Equipment filters apply to generated skill plans. Working level is selected by the athlete; AI cannot certify technique or bypass readiness checks.

The supplied Foundation content is implemented as four focus days. Graduation targets are recorded separately from starting doses and require repeated self-rated quality sessions. They are product benchmarks, not universal medical thresholds. Per-side instructions are shown for unilateral exercises; the app does not claim automatic form analysis.

AI recommendations select canonical exercise IDs and are validated again by shared rules. The server accepts the existing OpenAI key or Vercel AI Gateway identity when available; owner/member sign-in and the existing server quota remain required. A clearly labeled rule-based planner works without a model. Live provider completion still requires runtime authentication, credits and a signed-in session; configuration status alone does not prove a model request succeeded.

`server/coach-policy.mjs` is generated by `scripts/build-coach-policy.mjs` from the same TypeScript policy/catalog used by the client. No user symptom notes are sent to the model. Broader pending work remains cloud-synced progress, complete human video verification, physical-device Fold testing and coach-managed content publication.
